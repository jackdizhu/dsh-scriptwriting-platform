# 客户端构建链：最小配置产出 lazy-CJS 契约（D2-A）

- 状态：accepted（2026-11-21 用户拍板，经两轮答疑后确认）
- 日期：2026-11-21
- 关联功能：阶段 1 UI 静态部分（`docs/plans/2026-11-21-implementation-steps.md` §2.2、§3.6）
- 关联决策：`docs/decisions/2026-11-21-UI入口与承载位置.md`（D1 承载位置 β）

## 背景

`dsh-scriptwriting-ui` 要成为 dsh Web 插件，必须有浏览器半（`dsh.client` + `./client` 导出）。harness 规定浏览器半的产物不是普通 ESM，而是 lazy-CJS factory：运行 bundle 只向 `window.__ModuleLoader__.load()` 注册 factory，模块副作用在首次物化时才执行。该契约由 `ClientModuleLoaderTarget.load(registration)` 定义（`github-projects/deepseek-harness/packages/client/modules/src/client/manifest.ts:385-394`），实现见 `packages/client/modules/README.zh.md:12,43,85`。

生成该产物的官方预设 `packages/client/tsdown.client.ts` 有 1265 行，且顶部 import 了 6 个 harness 仓库内文件（`scripts/client-build-environment.ts`、`scripts/experimental-package-policy.ts`、`scripts/bundle-input-isolation.ts`、`modules/src/assets.ts`、`modules/src/client/manifest.ts`、`web/src/platform.ts`）与 `lightningcss`，无法在树外仓库原样运行。

## 选项与取舍

| 选项 | 做法 | 优点 | 代价 |
|---|---|---|---|
| **A. 最小配置复刻（已选）** | 新增 `packages/ui/tsdown.config.ts`：rolldown/tsdown，`format: 'cjs'`，`external` 只列 react 系，补 banner/intro/footer 契约 | 产物与 harness 同构；不引入 harness 源码；依赖最少；无升级同步负担 | 无 CSS Modules / purity gate（靠人工纪律）；echarts 内联需自己盯体积 |
| B. 整份复制 harness 预设 | 把 `tsdown.client.ts` 及 6 个仓库内文件一起搬入 | 功能最全（CSS Modules、资源哈希、纯净性检查） | 搬运 1265 行 + 6 文件 + lightningcss，随 harness 升级需持续同步；本期能力用不上 |
| C. 独立 HTML 原型 | 纯静态页面，浏览器直接打开 | 零构建风险，最快看到视觉效果 | 不在真实环境，slot 生命周期 / 主题变量 / 卸载清理无法验证；最终仍要走 A，双份实现 |

## 结论

采用 **A**。关键点：**这不是偏离插件标准，而是以最轻方式满足标准**——插件两半都按 harness 契约走；Node 半（具名导出 `apply`/`inject`）已是标准插件，浏览器半用最小配置产出标准 lazy-CJS factory。复刻的只是「打包那一步」约 40 行胶水，不是自创开发模式。

三条不可违反的边界：

1. `external` 只列 `react` / `react/jsx-runtime` / `react-dom` / `react-dom/client`；平台模块表 `PLATFORM_MODULES`（`packages/client/web/src/platform.ts:8-15`）不含 echarts，故 echarts 必须内联，不得出现在 `dsh.client.external` 或运行时 `require()`。
2. 不引入 CSS 管线（echarts / zrender 不依赖外部样式表，自家样式走内联对象）。
3. Apache-2.0 4(d) 要求分发携带 NOTICE，并入产物 banner 注释块（普通 tsdown 无 `postBanner` 钩子）。

- `pnpm -C packages/ui build` 后 `lib/client.js` 首行为 `window.__ModuleLoader__.load({ id: "dsh-scriptwriting-ui", factory: ...`，紧随 Apache NOTICE 注释块；
