# UI 入口与承载位置：左栏 `sidebar.panellist` 行 + 主列面板（β）

- 状态：accepted（2026-11-21 用户拍板选项 β）
- 日期：2026-11-21
- 关联功能：世界地图 / 人物关系 / 时间线的入口与承载位置（UI 静态阶段）
- 关联决策：`docs/decisions/2026-11-21-项目代码目录大纲.md`（包粒度）
- 关联计划：`docs/plans/implementation-steps.md` §2.1.1、§2.1.2

## 背景

阶段 1 要先把三块视图（世界地图、人物关系、时间线）做成可点开、可看的静态 UI。两件事必须先定：

1. **承载位置**：三块视图渲染在哪里；
2. **入口位置**：用户从哪里把它们叫出来，以及「打开 / 关闭右侧面板」的动作挂在哪个控件上。

承载位置经 §2.1.1 对比后取「右侧栏 tab 类型」：三块视图都是独立于对话流的结构化视图，天然属于侧栏，且 `guide` 字段能让它们出现在引导页。

入口位置的本能做法是在左栏插件按钮区加一行。但查证后发现该区域有硬约束：

| 事实 | 出处 |
|---|---|
| 插件按钮区是 `sidebar.panellist`（list, root scope），每行 `id` 是 `MainPanelId`，点击由壳层直接 `trackEntryClick()` + `selectPanel(id)`，**无覆盖钩子** | `packages/client/ui-sidebar/src/client/SidebarRoot.tsx` 的 PanelRow `onClick`（80–83 行） |
| `selectPanel(id)` 只做 `activePanelId = id` 赋值，**幂等**，重复点击同一行不产生状态变化 | `packages/client/ui-layout/src/client/stores.ts` 的 `selectPanel`（94–97 行） |
| 主面板是否「已注册」由 `main` 槽位的 keyed 注册决定；未注册时 `selectPanel` 抛错 | `packages/client/ui-layout/src/client/service.ts`（72–78 行）、`AppFrame.tsx`（46–49 行，`renderSlot('main', …{ entryKey: panelId ?? 'conversation' })`） |
| 左栏能放自定义交互控件的另一个座位是 `sidebar.session.action`（hoc，包住新建会话行），但受 `canStartSession` 门控 | `SidebarRoot.tsx`（351 行） |

即：**插件按钮区的一行不能承载「开关右栏」的点击**——它的点击语义被壳层固定为「切主列」。

## 选项与取舍

| 选项 | 落点 | 优点 | 代价 |
|---|---|---|---|
| α | `sidebar.session.action`（hoc） | 位置紧邻插件按钮区上方；不占主列；点击可自由绑定为开关 | 无建会话权限时整行不渲染；hoc 语义是「环绕」，加按钮需破坏并排布局 |
| **β（已选）** | `sidebar.panellist` 行 + `main` 主列面板 | 按钮**物理落进**插件按钮区，与「插件」「任务管理器」同排，位置最准 | 必须同时注册一个主列页面；点击会切走主列；**重复点击无法关闭**（`selectPanel` 幂等） |
| γ | `sidebar.footer.action` | 渲染最稳定，不受权限门控 | 位于底部 Settings 旁，与「工作区上方」不符 |

## 结论

采用 **β**：左栏插件按钮区新增「创作平台」行，点击进入同名主列页面，并在同一步把右侧面板展开到上次使用的视图。

由 `selectPanel` 的幂等语义推导出的两条**已知代价**，用户已知悉并接受：

1. **再点同一行不会关闭右侧面板**——壳层不会产生第二次状态变化，我们也拿不到该点击。「关闭」改由两个落点承担：主列页面内的「收起右侧面板」按钮，以及右侧栏自带的收起控件。
2. 点击会**替换主列内容**（对话流被「创作平台」页取代），返回对话需用壳层自己的返回控件。

因此「创作平台」页不是空占位，它必须承担真实职责：三块视图的入口卡（点卡片切右栏 tab）、当前视图摘要、以及「收起右侧面板」按钮。

## 验证方式

阶段 1 实施后逐条验证（`docs/plans/implementation-steps.md` §3.10 的第 13–15 步）：

1. 左栏出现「创作平台」行，与「插件」同排、位于工作区列表之上；
2. 点击 → 主列显示创作平台页，且右侧面板展开到上次的视图（首次为世界地图）；
3. 再次点击同一行 → 主列不变、**右栏不关闭**（这是 β 的预期行为，不是缺陷）；
4. 点页面内「收起右侧面板」→ 右栏收起；
5. 右栏先开着「文件」时点击该行 → 切到我们的视图，不关闭右栏；
6. 卸载插件后，行与主列页面同时消失，`selectPanel` 不再认可该 id。
